# 公开通知案例搜集（2026-10-23）

本轮交付是来源可追溯的案例索引，不是已经获得训练授权的大规模真实语料库。未加入 APK、未训练、未导入个人学习数据。

## 实际数量

- `source-index.jsonl`：18 个 App 的案例来源记录，不代表 18 条已取得的通知正文。
- `quoted-excerpts.jsonl`：5 条网页短引文，涉及 5 个 App；其中 2 条是来源网站的英文翻译卡片，3 条仅为片段。两份文件有重叠，不能相加作为样本数。
- 本轮新增可直接投入训练、具有确认授权及用户标签的真实通知：0 条。
- 所有 label 均为空，training_eligible=false；包名没有根据 App 名称猜测。

## 来源及限制

1. [中文实收通知分析](https://www.woshipm.com/operate/385051.html)：作者记录自己一周收到的消息，有小红书、饿了么案例。发布时间 2016 年，较旧；截图包含 push 与短信，不能混算。正文核对完成，图片请求超时，图片未逐字核对，保留原图 URL 待复核。
2. [Pushwoosh 跨行业案例](https://www.pushwoosh.com/blog/push-notification-examples/)：页面称来自真实品牌案例，覆盖购物、金融、出行、新闻、游戏等。我们核对的是发布者的案例说明；没有独立设备采集证据，也没有逐字 OCR 截图。截图仅保存链接，不复制图片。
3. [AO.news 一年通知采集](https://ao.news/data/year-of-push-notifications)：发布者报告 537,376 条、336 个新闻 App。公开 CSV 是聚合统计，不含通知正文；网页卡片为英文翻译。没有下载到这 53 万条文本，不能列入本地语料数量。页面事件聚类摘要不属于单 App 原始文案，未收录。
4. [AmI 2018](https://github.com/komis1/ami2018-notifications)：176,195 条真实通知记录，但 README 字段为包名、时间、优先级、设备状态等，没有标题和正文；不适合此次内容分类训练，未下载数据库。
5. [NotifAI](https://huggingface.co/datasets/charlesfeng1/notifai-dataset)：数据卡明确为 Claude 生成的合成通知。Viewer 显示 10.8k 行，而说明另称 16,000 条，数量不一致。未下载，不能算真实通知。
6. [PersoNo](https://jyzheng.com/assets/pdf/PersoNo.pdf)：实验使用外部文本并分配发送人占位符，不能将实验条数当作原生 WhatsApp 通知采集数。

## 后续使用规则

这些网页案例可用于人工研究覆盖场景。欲转为训练数据，需要补齐正文核验、适用使用许可、去重及人工标注，保留原文与翻译的区别。短引文不能冒充完整通知。

“订单、支付、营销、聊天、新闻”等是内容类型；“正常/骚扰”是用户偏好，两者分开。没有用户反馈时不擅自给正常/骚扰标签；低紧急度也不等于骚扰。

现有小型语义编码器已经预训练，本轮找不到大规模真实训练库不影响它运行，但不能据此声称在真实通知上达到某种准确率。个人纠正样本依旧是本项目个性化判断的直接依据。
