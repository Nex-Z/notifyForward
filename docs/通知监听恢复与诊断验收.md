## 边界

- 应用无法自行开关系统的通知访问授权。自动重连无效时会提示用户手动关闭再开启授权。
- 前台保活关闭、应用被强行停止或受到系统后台限制时，检查可能延迟，不能承诺固定恢复时间。
- 当前已有原生库出现系统 16 KB 对齐兼容性提示（MMKV / ONNX Runtime）；本次没有升级这些依赖，不能由此判定此前断连的根因。
- 后续 1.1.6 已升级原生库并消除当前设备的该提示，详见 [16 KB 兼容性验收](16KB原生库兼容性验收.md)。
