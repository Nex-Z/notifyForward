# 1.1.1 应用范围、转发记录与弹窗调整

- 删除同应用 60 秒 5 次通知触发全局勿扰的自动执行路径，设置入口移除。旧开关值不会再触发该机制。
- 手动规则的勿扰功能仍保留，明确标注为全局勿扰，会影响其他应用；不是单应用静音。
- 系统 category=call 的通知不执行消除、勿扰或通知按钮动作；含 fullScreenIntent 的通知在服务端同样保护。应用未正确提供这些标记时不能保证识别，不宣称覆盖所有微信机型。
- 个人学习严格按包名和分身隔离；微信、QQ、WhatsApp、Telegram 没有本应用个人标注时返回不确定。仍有通用参考样本，没有可靠的好友/群聊/公众号身份识别。AI 仅观察。
- 新建规则默认仅指定应用、默认不消除通知；已有规则不自动改写。请检查旧的“所有应用”规则是否仍符合意图。
- 本地效果按优先级执行首条匹配的效果规则；所有符合各自应用范围及文本条件的转发规则独立执行。多条重叠转发规则可能向同一目标发送多次，每次分别记账。
- 历史增加“转发记录”筛选，包含发送中、成功和失败；详情展示时间、渠道、规则和 HTTP 结果。服务端确认不代表接收设备已展示。
- 发送前持久化记录，未完成超过两分钟展示为结果未确认，避免将进程中断误报成功；不自动重试。旧版本只能展示原有结果，无法补回逐次流水。历史删除同时删除对应流水，个人标注保留。
- 应用选择弹窗移除重复操作栏，显示已选数量及包名，高度随屏幕调整；通知详情展开、正文增强对比、转发段落独立、删除与标注分开并确认。

验证：模拟器 29 项验收通过，含实际通知监听到本地 HTTP 接收器的 Bark/Webhook 链路。真实手机微信来电和厂商后台行为尚未验收。弹窗在 Pixel 模拟器上完成视觉检查。APK 为 debug 1.1.1（versionCode 3）。
